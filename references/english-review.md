# 英文审阅与版本对比

1. **先对齐论点。** 按事实、判断或论证步骤配对，即使两版分句不同也按同一意思比较。标记新增、删减和未变化处。单稿审阅时，先复述段落主张，找出无法确定的地方。
2. **检查证据与含义。** 核对对象、样本范围、时间、条件、否定和确定程度。检查连接词是否准确表达因果或转折。来源有争议时查原始材料，缺少来源就指出待核实处。评价分数和检测标签与语言判断分开。
3. **定位阅读负担。** 找出主语与主要动词，检查代词指向、词义和搭配。陌生搭配可查词典或可靠语料。保留有用的术语、被动语态和必要的重复。调整节奏时检查完整句与有意使用的残句。
4. **看段落是否推进。** 概括每段作用，检查证据支持哪个主张、下一段增加了什么。学术写作区分观察、解释与结论。反思写作交代真实选择、理由及限制，素材缺失时请作者补充。

对每处值得讨论的差异，给出**具体变化、阅读效果、意义影响和判断**。判断可以是改善、取舍、退步或待核实。先指出改变结论的地方，再谈语言。

| 原文与改动 | 如何判断 |
|---|---|
| “In this pilot, response times fell.” → “The system reduced response times.” | 句子更直接，但删去试点范围，并把观察改成因果。需要证据才能采用。 |
| “The team changed the form and extended the deadline. This improved completion.” | `This` 可能指一个改动或两个。原始证据无法区分时保留不确定性。 |
| “The logs were retained for 30 days.” | 保留时长是重点。施事者无需补写，被动结构清楚。 |

维护此 Skill 时用原句和修改版复跑上述样例，再加一条中文口述样例：「我还没决定要不要上线。三个同事看过测试版。」润色应保留未决定、三人、测试版和看过的动作。区分链接与元数据检查、AI 样例评估和人工确认。
