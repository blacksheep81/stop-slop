# 中文编辑参考

先看段落有没有推进观点。连续几段若只是换词重复同一个结论，合并它们。该转场时把关系交代清楚，读者能跟上时直接进入下一段。保留能承担论证的例子、小标题和清单。

| 检查信号 | 怎样判断与处理 |
|---|---|
| 翻案句 | 只用于抬高语气时，直接说主张。否定涉及实际排除范围、修正误解或对照实验时保留。 |
| 长前置定语 | 找到中心名词，把目的、条件、限制移到读者容易吸收的位置。保留它们之间的逻辑关系。 |
| 密集并列与四字格 | 删同义凑数，保留独立功能、规格和论点。真正并列的内容可用清单。 |
| 假转折与结论冒号 | 去掉重复的结论预告，直接陈述。引语、列项和确有解释作用的标点照常用。 |
| 同义词轮换 | 同一对象沿用清楚的名字。为求变化而换词容易让读者误以为出现了新概念。 |
| 生硬比喻 | 看比喻能否解释对象的实际关系。只有情绪或气氛时优先写可观察的动作或结果。 |
| 空泛褒义、万能背景与收尾 | 把已有事实移到前面。缺少具体证据时，删装饰性措辞，保留作者确实表达的判断。 |
| 口述碎片 | 去口头禅、纠正明确的改口和重复，保留第一人称、犹豫、幽默及语气强度。 |

## 对照例子

- 润色输入：这是一套能够帮助编辑在不增加人手的情况下处理更多稿件的工具。改为：这套工具帮助编辑处理更多稿件，团队无需增加人手。
- 技术边界：关闭缓存后可能出现超时，目前只在测试环境复现。保留“可能”“只在测试环境”和当前完成状态。
- 真对比：错误发生在导出阶段，上传已经成功。保留两个阶段的信息。
- 口述输入：我其实还没决定要不要上线，试过的是测试版，三个同事看过。保留“未决定”“测试版”“三个同事看过”，不要补成试用成功或一致认可。

风格信号来自样本和语境。编辑时查看频繁出现的模式及其实际作用，单次命中不足以说明有问题。
